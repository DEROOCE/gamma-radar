使用方法

1. 关键位默认由 CBOE 期权链每日自动估算；如你有更准的数据源（SpotGamma 等），点「⚙ 配置」手动覆盖。

2. 看「市场状态」确定震荡市还是趋势市。

3. 盘中只盯价位地图上的 3–4 个价格，Alert 触发时自动亮灯。

4. 触发 Alert 时再决策，区间内部不追涨杀跌。

数据说明：行情为公开延迟数据（CNBC，约延迟 15 分钟），60 秒自动刷新。Dealer Gamma、Gamma Flip、Call/Put Wall 均为估算值——交易所不公布真实做市商持仓。关键位默认由 CBOE 延迟期权链（真实 OI + IV）每日自动估算（简化 GEX 模型：Dealer 多 Call / 空 Put），可在「⚙ 配置」中手动覆盖（保存在本地浏览器）。0DTE 仓位会盘中快速改变结构，正确用法是：盘前看自动 Base Case → 盘中监控 Flip / Wall 突破 → Alert 自动触发。本页面不构成任何投资建议。
